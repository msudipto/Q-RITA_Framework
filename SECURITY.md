# Security Policy

## Supported Versions

This framework is an active research project. Security updates are applied directly to the primary development branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < main  | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability or issue within this framework, please do not open a public GitHub issue. Instead, report it privately by contacting the maintainers via email:

* **Mubassir Serneabat Sudipto** — msudipto@iastate.edu
* **Shakil Ahmed** — shakil@iastate.edu

Please provide a brief description of the issue and steps to reproduce it so we can address it responsibly.
